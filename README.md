<em> # Challenge amigo secreto - README </em>

En este programa que fue hecho en HTML, CSS y javaScript permite que el usuario agregue nombres de amigos a una lista la cual al terminar de agregar puede realizar un sorteo aleatorio.

Caracteristicas:

-Agregar nombres a una lista desde una caja de texto.
-No acepta nombres repetidos ni vacios.
-Muestra los nombres que ya agrego el usuario.
-Realiza el sorteo de manera aleatoria.
-Muestra el resultado en negritas.
-Realiza una validacion para que no se pueda hacer el sorteo solo con 1 nombre.

Uso para el usuario:

-Abre index.html en el navegador.
-Escribe el nombre de tu amigo en la casilla y preciona en 'añadir'.
-Realiza lo mismo las veces que sezn necesarias.
-Preciona en el boton 'Sortear amigo' para que arroje un resultaqdo aleatorio.
